# Roviro | Portfólio Profissional de Engenharia de Software

Repositório oficial do portfólio profissional de **Jeferson Roviro** ([roviro.com.br](https://roviro.com.br)), desenvolvido com foco em alta performance, arquitetura visual moderna (Dark Glassmorphism) e conversão direta para clientes e oportunidades B2B.

---

## 🛠️ Tecnologias & Arquitetura
- **Interface & Estilo:** Tailwind CSS (estendido com tema customizado e gradientes modernos), CSS Grid avançado, Glassmorphism e tipografia Bricolage Grotesque / Plus Jakarta Sans.
- **Interatividade & Lógica:** Vanilla JavaScript modular para o simulador interativo de orçamento, integração direta com API de WhatsApp e feedback dinâmico via toasts.
- **SEO & Performance:** Meta tags Open Graph, tags do Twitter/X, semântica HTML5 estrita e Score 100 em Core Web Vitals.
- **Deploy:** Servidor Linux Nginx com proxy reverso e SSL/TLS automático.
